# 🚀 DeepLoader

**The most advanced free Android media downloader.**

Built by **Sonu Verma** • Zero Cost • 100% Cloud Built

---

## ✨ Features

- **Universal Downloader** — YouTube, Instagram, Twitter/X, TikTok, Reddit, Facebook, SoundCloud, Vimeo, Dailymotion, 1000+ sites
- **Torrent Engine** — Built-in torrent search & download with DHT/PEX peer discovery
- **Stream & Download** — Start watching while downloading via sequential torrent streaming
- **4K Support** — Download up to 4K Ultra HD quality
- **Multi-threaded** — 16-32 parallel chunk downloads for maximum speed
- **Smart Extraction** — 3-layer fallback: NewPipe → yt-dlp → Innertube
- **Pause & Resume** — Never lose progress, even after app kills
- **MP3 Converter** — Convert any video to MP3 (128/192/320 kbps)
- **Clipboard Watcher** — Auto-detect URLs from your clipboard
- **Share-to-Download** — Share a link from any app to start downloading
- **Biometric Lock** — Protect the app with fingerprint or PIN
- **Three Themes** — Light, Dark, and AMOLED (pure black for OLED screens)
- **WiFi-Only Mode** — Save mobile data
- **Background Downloads** — Downloads continue even when the app is closed

## 🛠️ Built With

- **Kotlin** — 100% Kotlin, no Java
- **Jetpack Compose** — Modern declarative UI with Material3
- **NewPipe Extractor** — Native YouTube extraction
- **yt-dlp** — 1000+ site support as fallback
- **OkHttp** — High-performance parallel downloads
- **Room** — Local database for download history
- **ExoPlayer/Media3** — Built-in video player
- **WorkManager** — Reliable background processing
- **Hilt** — Dependency injection
- **GitHub Actions** — Automated APK builds

## ☁️ 100% Cloud Development

**No Android Studio required!** Everything runs in the cloud:

1. **Code** in GitHub Codespaces (VS Code in browser)
2. **Build** automatically via GitHub Actions
3. **Download** APK from GitHub Releases

## 📱 Install

1. Go to [Releases](https://github.com/SONUVERMA11/DeepLoader/releases)
2. Download the latest APK
3. Enable "Install from unknown sources" on your phone
4. Install and enjoy!
